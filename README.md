# AZIZ FELINES CATTERY — React/Vite Website

Six responsive pages recreated from the supplied mockups:

1. Home
2. About Us
3. Services
4. Gallery
5. Customer Reviews
6. Contact Us

## Run
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

## Notes
- Supplied logo and available cat imagery were extracted from the uploaded mockups and placed in `public/images`.
- Where a clean source image was not available, the layout uses a cropped mockup image or a simple placeholder-style visual.
- WhatsApp, email, navigation, service anchors, gallery/review filters, enquiry form and responsive mobile navigation are functional.
